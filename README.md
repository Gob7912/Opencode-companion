# OpenCode Companion

Спутник OpenCode для angelOS — в стиле и по конвенциям `claude-companion` и `codex-companion`.

## Возможности / Features

- **Панель (Bar Widget)**:
  - Пиксельный робот-маскот с интерактивной анимацией и индикацией статуса (работает / готово).
  - Счётчики активных сессий и токенов за сегодня.
  - ЛКМ — расход токенов и быстрый вопрос, ПКМ — карточки активных сессий, СКМ — быстрый вопрос.
- **Уведомления на рабочий стол**:
  - Автоматическое уведомление (`notify-send -a "OpenCode"`), когда OpenCode заканчивает выполнение задачи в любом терминале или фоновом чате (без спама на промежуточных вызовах инструментов `tool-calls`).
- **Виджет на рабочем столе (`Orb.qml` / `opencode.exe`)**:
  - Робот, текущий статус, токены за сегодня.
  - Поддержка кругов ада (`Theme.hell`): демонические рожки и инфернальная палитра.
- **Сайдбар (`SidebarBlock.qml`)**:
  - Компактный блок со статусом и расходом за сегодня.
- **Лаунчер (`Launcher.qml`)**:
  - `oc` — продолжить последнюю, начать новую или открыть недавнюю сессию напрямую в рабочей директории.
  - `oc <задача>` — запустить OpenCode в терминале с заданным промптом.
  - `oc ? <вопрос>` — быстрый вопрос без сохранения в проект, ответ доставляется системным уведомлением.
- **Карточки сессий**:
  - Просмотр недавних сессий и кнопка «Открыть» для прямого запуска в нужной директории проекта.
- **IPC API**:
  - `qs -c angelos ipc call opencode status`
  - `qs -c angelos ipc call opencode refresh`
  - `qs -c angelos ipc call opencode resume`
  - `qs -c angelos ipc call opencode newSession`
  - `qs -c angelos ipc call opencode ask "<вопрос>"`

## Безопасность и данные

- **Только локально**: читается исключительно локальная база `~/.local/share/opencode/opencode.db` (SQLite, режим `mode=ro`).
- Содержимое файлов и переписки **никогда не читается и не передаётся по сети**.
- Подсчёт токенов ведётся накопительным приростом между сканами в `~/.cache/angelos/opencode-scan.json` (удаление сессий не приводит к провалам в суточной статистике).

## Требования / Requirements

- angelOS / Quickshell
- OpenCode CLI (`opencode`)
- Python 3 with `sqlite3` (входит в стандартную библиотеку)

## Настройки / Settings

- Режим значка на панели: Авто / Сессии / Токены / Только значок.
- Показывать виджет на рабочем столе: Всегда / Когда активен / Скрыт.
- Уведомление по окончании: вкл / выкл.
- Интервал обновления.
